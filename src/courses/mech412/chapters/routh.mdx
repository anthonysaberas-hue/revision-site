# Routh–Hurwitz stability

<div className="lede">

A closed loop is only useful if it is **stable**: all its poles in the left half-plane. Finding poles means solving a polynomial, which is hopeless by hand beyond degree two. The **Routh array** answers "how many roots are in the right half-plane?" and "for which gains is the loop stable?" using only arithmetic on the coefficients.

</div>

<Idea title="The 30-second version">

Take the characteristic polynomial $a_0s^n+a_1s^{n-1}+\dots+a_n$. Build a table (the Routh array) from its coefficients with a simple recipe. **The number of sign changes in the first column equals the number of roots in the right half-plane.** If all coefficients are positive and the first column has no sign change, the system is stable. To find the allowed range of a gain $K$, require every first-column entry to stay positive.

</Idea>

## Why the first quick test is only necessary

Expand $\prod(s-p_i)$: the coefficients are sums and products of the roots. If every root has a negative real part, **all coefficients must be non-zero and of the same sign**. That is a free first check: a polynomial with a missing term or a sign change is *already* unstable. But the converse is false: $s^3+s^2+s+10$ passes the test and is unstable. That is what the array adds.

## Building the array

For $a_0s^n+a_1s^{n-1}+a_2s^{n-2}+\dots$ the first two rows are the coefficients taken alternately:

| row | | | |
|---|---|---|---|
| $s^n$ | $a_0$ | $a_2$ | $a_4$ |
| $s^{n-1}$ | $a_1$ | $a_3$ | $a_5$ |
| $s^{n-2}$ | $b_1$ | $b_2$ | $b_3$ |
| $s^{n-3}$ | $c_1$ | $c_2$ | |
| $\vdots$ | | | |

$$
b_1=\frac{a_1a_2-a_0a_3}{a_1},\quad b_2=\frac{a_1a_4-a_0a_5}{a_1},\quad c_1=\frac{b_1a_3-a_1b_2}{b_1},\quad c_2=\frac{b_1a_5-a_1b_3}{b_1}.
$$

*Pattern:* each new entry is **(entry diagonally to the lower-left × entry above) minus ... , divided by the first entry of the row above**: a 2×2 determinant over the pivot. Missing entries are zeros.

**Rule: sign changes in the first column = roots with positive real part.**

**Third order shortcut:** $a_0s^3+a_1s^2+a_2s+a_3$ is stable iff all $a_i>0$ and $\mathbf{a_1a_2>a_0a_3}$.

**Second order shortcut:** $s^2+as+b$ is stable iff $a>0,\;b>0$ (all coefficients the same sign).

### Worked example 1 (HW7 Q1a): $s^4+8s^3+32s^2+80s+100$

| | | | |
|---|---|---|---|
| $s^4$ | 1 | 32 | 100 |
| $s^3$ | 8 | 80 | |
| $s^2$ | $\dfrac{8\cdot32-1\cdot80}8=22$ | $\dfrac{8\cdot100-0}8=100$ | |
| $s^1$ | $\dfrac{22\cdot80-8\cdot100}{22}=43.6$ | | |
| $s^0$ | 100 | | |

First column $1,\,8,\,22,\,43.6,\,100$: **no sign change ⇒ stable** (roots $-1\pm3j$, $-3\pm j$ ✔).

### Worked example 2 (HW7 Q1b): $s^4+2s^3+7s^2-2s+8$

| | | | |
|---|---|---|---|
| $s^4$ | 1 | 7 | 8 |
| $s^3$ | 2 | −2 | |
| $s^2$ | $\dfrac{2\cdot7-1\cdot(-2)}2=8$ | $\dfrac{2\cdot8-0}2=8$ | |
| $s^1$ | $\dfrac{8(-2)-2\cdot8}8=-4$ | | |
| $s^0$ | 8 | | |

First column $1,2,8,-4,8$: **two sign changes ⇒ two RHP roots** (they are $0.31\pm0.98j$).

## Finding the range of a gain $K$

Put $K$ in the polynomial, build the array symbolically, and demand every first-column entry $>0$.

**Example** $s^3+3s^2+2s+K$ (the loop $\dfrac{K}{s(s+1)(s+2)}$):

| | | |
|---|---|---|
| $s^3$ | 1 | 2 |
| $s^2$ | 3 | $K$ |
| $s^1$ | $\dfrac{6-K}3$ | |
| $s^0$ | $K$ | |

Stable iff $\dfrac{6-K}3>0$ and $K>0$: $\boxed{0<K<6}$. At $K=6$ the $s^1$ row is zero and the **auxiliary polynomial** from the row above, $3s^2+6=0$, gives $s=\pm j\sqrt2$: the loop oscillates at $\omega=\sqrt2$ rad/s. This $K_{cr}$ and $\omega_{cr}$ are exactly what Ziegler–Nichols uses (Chapter 17) and what the Bode gain margin finds (Chapter 19).

**HW7 Q2:** $s^5+5s^4+10s^3+10s^2+5s+k$. Rows: $s^3$: 8 and $\tfrac{25-k}5$; $s^2$: $\tfrac{55+k}8$ and $k$; $s^1$: $\dfrac{1375-350k-k^2}{5(55+k)}$; $s^0$: $k$. Conditions: $k>0$ and $k^2+350k-1375<0$, i.e. $\boxed{0<k<-175+80\sqrt5=3.885}$.

## Special case 1: a zero in the first column

If the first entry of a row is zero but the row has other non-zero entries, **replace the zero by a small $\varepsilon>0$**, continue, then let $\varepsilon\to0^+$ and count sign changes.

Example $s^3-3s+2$: rows $1,-3$; $0\to\varepsilon,\;2$; $\dfrac{-3\varepsilon-2}\varepsilon,0$; $2$. The third row is $-\infty$ as $\varepsilon\to0^+$ so the column is $1,\varepsilon,-\infty,2$: **two sign changes ⇒ two RHP roots** ($s^3-3s+2=(s-1)^2(s+2)$ ✔).

## Special case 2: a whole row of zeros

A row of all zeros signals roots **symmetric about the origin** (pairs $\pm\sigma$, $\pm j\omega$). Build the **auxiliary polynomial** $P(s)$ from the row *above* the zero row (its entries are the coefficients of alternating powers), replace the zero row by the coefficients of $dP/ds$, and continue. The roots of $P(s)$ are roots of the characteristic polynomial.

**Example** $s^5+2s^4+24s^3+48s^2-25s-50$:

| | | | |
|---|---|---|---|
| $s^5$ | 1 | 24 | −25 |
| $s^4$ | 2 | 48 | −50 |
| $s^3$ | 0 | 0 | (zero row) |

1. Auxiliary $P(s)=2s^4+48s^2-50$; $\dfrac{dP}{ds}=8s^3+96s$ ⇒ new $s^3$ row: $8,\;96$.
2. $s^2$: $\dfrac{8\cdot48-2\cdot96}8=+24$ and $-50$ (Anthony's page prints $-24$; the correct value is **+24**).
3. $s^1$: $\approx112.7$; $s^0$: $-50$.
4. First column $1,2,8,24,112.7,-50$: **one sign change ⇒ one RHP root.**
5. Check: roots are $\pm5j$ (marginal pair), $+1$ (RHP), $-1$, $-2$. The auxiliary polynomial gives $s^2=1$ and $s^2=-25$.

*Another one:* $s^3+2s^2+s+2$ gives a whole zero row at $s^1$ (auxiliary $2s^2+2=0$): roots $-2,\pm j$: **marginally stable**.

## Relative stability

Shift the axis: substitute $s=z-\sigma$ and apply Routh in $z$. No sign change means all poles lie to the left of $-\sigma$: a stability margin $\sigma$.

## Putting it together: the stability range as a design tool

For the closed loop $1+KG(s)=0$ the characteristic polynomial is $D(s)+KN(s)$. Routh gives the *interval of $K$* (here the loop is stable only for $0<K<6$); root locus (Chapter 18) shows the *picture* of how the poles move. A characteristic polynomial **with no $s^3$ term** (such as $s^4+6s^2+Ks+K$) can never be stable: the first test fails for every $K$ (HW8-2024 Q3b: $K(s+1)/[s^2(s^2+6)]$).
